# 🗓️ Общее время

**Каждый отмечает свободные часы и пересылает ссылку — приложение находит время, удобное всем.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/meet-time/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Рисование доступности пальцем или мышью
- Данные в ссылке: битовые маски в base64
- Тепловая карта и список лучших окон
- Без регистрации и сервера
- Share API на телефоне

## Стек

JavaScript. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/meet-time.git
cd meet-time
python3 -m http.server 8000
```
